# 🚲 Szprycha — Serwis Rowerowy

Responsywna strona internetowa fikcyjnego serwisu
rowerowego Szprycha w Bydgoszczy.

Projekt wykonany w ramach przedmiotu
**Technologie internetowe — Laboratorium 1**.

## 🌐 Strona internetowa

https://patrykjutrowski.github.io/ti-lab-jutrowski/

## 📖 O projekcie

Strona prezentuje ofertę serwisu rowerowego.

Zawiera:

- Stronę główną z kartami usług
- Cennik usług rowerowych
- Podstronę z ofertą
- Podstronę O nas
- Podstronę Kontakt
- Responsywny układ strony

## 🛠️ Technologie

- HTML5
- CSS3
- Flexbox
- Media Queries
- Git i GitHub
- GitHub Pages

## 📁 Struktura projektu

```text
ti-lab-jutrowski/
├── index.html
├── uslugi.html
├── o-nas.html
├── kontakt.html
├── style.css
└── README.md
```

## 🚀 Uruchomienie

1. Pobierz lub sklonuj repozytorium.
2. Otwórz folder w Visual Studio Code.
3. Uruchom plik `index.html` w przeglądarce.
